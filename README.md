This project is an interactive recipe card for a chocolate cake. I built it as a single-page layout that shows the recipe title, image, ingredients, instructions, preparation time, and serving size in a clear and organized way. The goal was to make the recipe feel more engaging than a normal static page by adding small animations and interactive buttons.
The card has buttons to show or hide the ingredients and steps, which keeps the page neat and easy to use. There is also a “Start Cooking” button that begins the cooking guide by highlighting the first step. When the user clicks “Next Step,” the highlight moves forward through the instructions one step at a time. At the same time, the progress bar updates to show how far the user has gone in the recipe. I also added a countdown timer to match the preparation time.
For the design, I used CSS to create a clean layout with good spacing, colors, and hover effects. The page is fully responsive, so it works well on mobile, tablet, and desktop screens. I also included print-friendly styling so the recipe can be printed in a simpler format if needed.
